# AudioPhile 1.0.0 — Release Notes

## Highlights
- Punk‑rock inspired UI with sharp, angular audio graphics.
- Batch mastering pipeline with peak/RMS normalization, compression, and limiting.
- Downloadable WAV/MP3 outputs plus waveform snapshots and in‑app audio preview.

## What’s Included
- Folder/file intake with progress + status indicators.
- Server‑side FFmpeg processing and verbose logs.
- Electron desktop app and Dockerized server.
- Linux distribution targets (AppImage + .deb).

## Downloads
- macOS: `AudioPhile-1.0.0-arm64.dmg`
- Linux: `AudioPhile-1.0.0.AppImage`, `AudioPhile-1.0.0.deb`

## Installation
See [INSTALL.md](INSTALL.md).

## Notes
- macOS builds are unsigned unless you complete Apple code signing.
- For Linux, prefer AppImage for portable usage or .deb for system install.
